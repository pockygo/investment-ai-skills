# 清单字段与计数

目标期间与文件分开：一个目标可能有原件和订正等多个文件，一个IPO也可能覆盖多个期间。小任务可用JSON数组关联，无需数据库。

## 公司表

`company_id`、上市主体名称、历史名称、市场、代码（文本）、母子公司关系、排序、产业链位置（适用时）、目录。

## 目标表

`target_id`、`company_id`、要求的类型、归档标签、预期起止日、年度口径、截至日、取得状态、关联文件ID、缺失原因、检索过的官方目录及核验日期。

稳定键使用“公司＋实际起止日＋要求类型”，不按Excel行号。日期暂不明确时用约定标签，确认后补齐。

## 文件表

| 字段 | 含义 |
|---|---|
| document_id / company_id / target_ids | 文件ID、主体、关联目标 |
| original_title / document_type | 原始标题与真实类别 |
| period_start / period_end | 实际期间，不能从下载日期反推 |
| reporting_scope | 合并、单体、集团等；不明则未确认 |
| role / related_document_id | 目标、订正、替换、补充；关联原件 |
| landing_url / source_url / final_url | 公告／目录、请求地址、重定向地址 |
| fetched_at / checked_at | 下载与核验时间 |
| relative_path / local_path | 归档相对路径与当前绝对路径 |
| bytes / pages / sha256 | 完整性与去重线索 |
| download_status / validation_status | 下载与内容核验分别记录 |
| qualifies_target / notes | 是否满足目标要求及理由 |

交付清单不保存Cookie、令牌或整段正文。

## 状态和数量

- **已取得**：身份、期间、类别核验通过且满足要求；存在必要订正报告时一并保存关联。
- **待核验**：文件落盘，但身份、期间、类别或完整性待确认。
- **截至日未见披露**：官方目录未找到本期报告，保留日期。
- **未检索到独立报告**：常见于上市前或历史缺失，不等于从未披露。
- **受限／失败**：找到候选但未能合法取得或验证。

完成数按唯一 `target_id`，PDF数按实际文件。一个IPO对应两个目标，实际文件仍只算1份；部分覆盖不能使目标自动完成。补充／订正不重复增加目标数。

例如14公司×3年=42目标，13家各取得3份完整报告，另一家仅有3份单体财务公告，另保存3份订正报告：完成39、缺口3、新增PDF45、其中补充6。

## Excel

- 总览：公司、代码、市场、产业链（适用时）、按时间排列的各期状态、资料目录、主体备注。
- 明细：原始标题、实际日期、类别和口径、状态、本地文件、来源、备注、大小及页数，补充资料可筛选。
- 代码为文本，日期为可排序日期，大小和计数为数值。冻结标题及必要标识列，提供筛选。
- 本地链接可用验证过的相对路径或绝对文件URI。不要宣称可随目录移动，实际却写绝对路径；中文、空格需正确编码。
- 导出后检查真实链接目标，不能只看显示文字。增加期间列时同步扩展表、筛选、条件格式、公式，复核旧记录未覆盖。
