# 数据口径与验收

用于所有市场的取数、计算与终稿验收。重点是防止语义错误沿着时间序列、季度面板、档案卡、图表及正文传播，不能只核对数字字符串是否出现过。

## 1. 唯一数字底稿

在 `extracts/` 保存可机器读取的数字底稿（CSV/JSON 均可），每条关键记录至少有：指标、期间、单季/累计/期末、原文标签、原值、原币单位、归一化值、合并/母公司、总归母/含少数股东/持续经营等定义、原始/重述版本、报告文件、PDF物理页、表头或行名。派生记录另留公式及输入记录。布局不适配的脚本输出只作候选值，不能按固定行序强认收入、归母或扣非。

- 正文、速查表、档案卡、季度面板与图表取自同一已核验底稿。修订一个指标时重算所有依赖项，不局部改一个显示值。
- 对照原 PDF 的完整表头及归属行。相同数值出现在“持续经营归母”和“总归母”时，也不能据此认定语义等同。
- 未披露、无法计算、不可比分别说明；原值为零时保留零。原文仅有“未单列”不能写成“没有该项”。

## 2. 关键定义

| 项目 | 必须保持的区别 |
|---|---|
| 利润 | 总合并净利、总归母、持续经营合并净利、持续经营归母、扣非归母分别记录；扣非未披露不填替代值 |
| 重述 | 按指标逐项核实：重分类可改变持续经营收入/利润而不改变总净利；主序列用最新可比口径，无法重建则分段 |
| CAPEX/FCF | CAPEX 说明有形、无形等范围；同一主指标全篇一致。若同时列有形及全口径，另起清晰名称，FCF注明所减项目 |
| 债务/现金 | 列明借款、租赁及流动重分类是否包含；不能重复加总；受限现金、其他金融资产与现金等价物分开 |
| 分红 | 宣告与实际支付分开；普通与优先股分开；集团合计支付与归母股东分红分开；不得混作同一趋势 |
| 周转/利用率 | 平均余额周转天数与期末占用天数分开；分部利用率不能替代某产品或某工厂利用率；每一期回原表 |
| 份额/排名 | 保留产品、地区、金额/数量、日期、来源；BGA与FC-BGA、总体MLCC与AI服务器MLCC不互相外推 |

金额统一为原币百万元；原文元、千元、百万、十亿等换算记录倍率。正文改写为“亿/万亿”时反算校验：1百万元=0.01亿元，1十亿元=10亿元。原文精度与换算后精度不能伪装为更高测量精度。

## 3. 计算与一致性

以下至少通过脚本或可复算公式检查；`scripts/validate_outputs.py` 覆盖其中的标准化表间关系，其他项目保留项目内计算底稿。

- 同比、环比、CAGR、利润率、净现比、CAPEX占比、合计数与FCF。利润基数为零时不计算增速，负数时注明适用性；资产负债表增速与相同基准日比较。
- 最近完整年度与最新可比中期利润桥：毛利→费用→营业利润→营业外→税→持续/终止经营→少数股东→总归母；保留未解释差额，不编造归因以闭合。
- TTM按连续四季逐指标求和；缺一季或某字段就不求该字段。与“前一年FY＋本期累计−前一年同期累计”核对；年末TTM与年报核对。
- 年末季度应收、存货、有息负债与同年年报一致。期末余额不相减，也不从下一期取值填补。
- 年度表、季度表、速查表、档案卡与正文引用一致；最新中期独立列示，不能因避免年中/全年混比而省掉最新数据。
- 有估值时反算PE、PB、EPS及情景表；明确币种、股数、优先股、库存股、利润归属、净债务和基准日。不同来源倍数不一致先解释，不择高或择低支持结论。

## 4. 判断与证据

保留商业模式的收入—成本—利润—现金链条、分部驱动与完整利润桥。篇幅、批判性语气、章节齐全、估值章节均不自动提高研究质量。

- “事实”“公司解释”“研究推断”分开；公司未解释就明确写未解释，不替公司补理由。
- 精确归因比例、价格敏感性、利用率对利润率弹性等必须有模型、输入及适用范围；没有模型就只给方向。不能靠【分析】或【估算】标签豁免证据。
- 无指引不等于预测失败；无量化承诺不等于高兑现度；有扩产不等于创造价值；净现比高不等于销售回款好。资本配置结合项目时点、回报和周期阶段判断，不能只比周期高低点。
- 判断证据不足时用“待验证/无法评价”，并给能推翻或支持判断的跟踪指标。不强制打分，不用过度确定的褒贬替代核验。

## 5. 交付门槛

分别记录三类结果，不合并成一个“核验通过”：

1. **原文语义抽查**：报告期、终稿指标、原文标签/数值、原币单位、归属范围、页码、差异与修订。覆盖至少10项、3年，另检查支撑首页结论的派生值及正文单位换写。
2. **独立披露核验**：季度推导值对年报分季表、公司季度公告或后续可比披露；说明独立来源与覆盖指标。没有独立对照则记“未完成”，不把0个差异写成通过。
3. **内部计算与跨表勾稽**：运行一致性脚本并保留JSON；报告原文核验、模型推断和脚本未覆盖项的范围。FY−9M再加回FY只是内部恒等式。

另外核对经营四表的年度/半年度覆盖（来源限年报、半年报，季度经营信息不列入四表）与逐字段缺失说明（见 [经营信息完整性](operating-coverage.md)），以及2×2图表、逐季数据表、覆盖CSV的季度和可得指标集合；禁止通过删掉历史季度、异常值、客户变化或未披露行满足验收。

错字段、错单位、不可比数据相减、TTM缺失填零、未解释的核心表差异、漏掉财务面板/图表已有季度或年报/半年报已披露的四项经营信息属于阻断项：先修底稿及全部下游，再发布无保留终稿。无法解决时可交付明确标注的待核验稿和问题清单，相关结论降级；不因“有抽查表”宣称合格。

比较模型报告时，先统一输入、截止日与新增外部资料边界，再比较数据/口径、计算、证据和研究解释。清楚区分“写作更好”与“研究成果可用”。
