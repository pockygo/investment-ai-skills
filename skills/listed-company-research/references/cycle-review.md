# 周期复盘框架

本框架回答：**这家公司穿越周期的方式是什么**。适用于收入/毛利率呈明显波动的行业（制造、材料、元器件、化工、航运等）；无明显周期的公司可只做第 1、5 步。

## 1. 周期段落划分

基于多年收入 YoY、毛利率、CAPEX 序列的形态，划分周期段落（上行 / 下行 / 底部 / 复苏），给出当前所处阶段的判断与依据。段落划分以数据为准，不照搬管理层叙事。

## 2. 逐段复盘

每个段落一个分析单元：

- **行业背景**：管理层在当年年报中对景气的判断（引原文+页码），可得的行业数据
- **公司应对**：扩产 / 收缩 / 转型 / 降本 / 囤货等关键动作（带数据与页码）
- **结果**：收入 / 毛利率 / 份额 / 现金流的变化
- **归因**：alpha 还是 beta（见第 3 步）

## 3. alpha vs beta 归因

公司业绩变化中，多少来自行业景气（beta），多少来自公司自身行为（份额提升 / 新产品 / 降本，alpha）：

- 用公司增速 vs 行业/同行增速、毛利率 vs 同行的相对变化做证据
- 区分需求增长、提价、结构升级、并表和会计口径变化
- 归因判断标【分析】并给数据依据，不下无证据结论。没有分解模型、行业/同业基准和可复算底稿时只给方向，不编造 alpha 30%、beta 70% 等精确比例；标【分析】不豁免证据要求。

## 4. 管理层叙事检验

- **甩锅/揽功检测**：下行期全怪行业、上行期全归自身，是经典叙事偏差。逐年对比管理层归因的一致性。
- **拐点判断兑现**：管理层在底部/顶部的前瞻判断（如"行业即将复苏"），次年是否兑现，逐条记录。必须先有带日期和页码的原始前瞻表述；未发出预警或未给时间表不能判为“未兑现”。不能把披露经营数据本身当作诚实归因的证据。

## 5. 周期属性定性

一句话结论：公司更偏**周期型**（业绩随行业波动）还是**成长型**（能穿越周期），依据是什么。该结论进入报告首页与档案卡。

## 6. 周期高点/低点行为记录

- 周期高点的 CAPEX、并购、扩产公告（事后验证是否买在顶点）
- 周期低点的动作：逆势扩产、囤货、裁员、回购。区分主动新决策与此前承诺项目的延续，结合后续增量回报与替代解释判断；“低点扩产正确”与“被动扛周期”均需证据，不由动作名称直接推导。
