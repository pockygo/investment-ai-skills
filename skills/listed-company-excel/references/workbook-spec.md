# 工作簿结构与样式规范

本 skill 只产出两类表：**单季营收同比矩阵**、**单季盈利质量块**。不做年度汇总表加列。

## 1. 单季营收同比矩阵

### 布局

```text
A1:AB1  标题
A2      公司
B2:AB2  26Q3 ... 20Q1（最新在左）
A3      上游公司 1（MLCC：博迁新材）
A4      上游公司 2（MLCC：国瓷材料）
A5      空行
A6      中游说明（合并 A6:AB6；MLCC 场景为“浆”）
A7      空行
A8      下游公司 1（MLCC：风华高科）
...
```

### openpyxl 要点

- 标题合并区域按列数计算：`A1:{last}1`。
- 表头填充 `#2F5597`，白色 10pt 加粗。
- 数值用 `[Red]0.00"%";[Green]-0.00"%";0.00"%"`，正红负绿。
- 空值留空，不写 0。
- 冻结 `B3`。
- 列宽：A 14；季度列 7.6。

## 2. 单季盈利质量块

### 布局

```text
A1:Q1   标题
A3      公司名（代码）
B3:Q3   26Q3 ... 22Q4
A4      毛利率
A5      营收同比
A6      扣非同比
A7      扣非TTM
A8      空行
A9      下一家公司
...
```

### 样式

- 公司标题行：整行 `#2F5597` 蓝底白字，A 列左对齐，季度列居中。
- 指标标签：`#D9EAF7` 浅蓝底，9pt 加粗。
- 毛利率：`0.00"%"`，黑色。
- 营收同比/扣非同比：`[Red]0.00"%";[Green]-0.00"%";0.00"%"`。
- 扣非TTM：`0.00"亿"`，黑色。
- 公司块之间空一行，行高 8。
- 列宽：A 17；季度列 7.8。
- 冻结 `B3`。

## 3. 2×2 季度面板图墙

### 布局

```text
A1:Q1   标题
A2:Q2   上游｜粉（合并）
A3:H3   公司 1 名称        J3:Q3 公司 2 名称
A4      图 1               J4    图 2
A5:Q5   中游｜浆（合并说明）
A6:Q6   下游｜MLCC（合并）
A7:H7   公司 3 名称        J7:Q7 公司 4 名称
A8      图 3 / 占位        J8    图 4
...
```

### 规则

- 图片来自 `report/charts/quarterly_panel.png`，宽约 700px，等比缩放。
- 左图锚 `A{row}`，右图锚 `J{row}`；`A:H` 和 `J:Q` 各 8 列，`I` 列 3 字符间隔。
- 图所在行行高约 390pt；图上方一行公司名，合并 `A:H` / `J:Q`。
- 按上游 → 中游 → 下游、两列 × N 行排列；同行的左右顺序、行间上下顺序都要保持。
- 无图的公司在对应位置放灰色占位说明，不拿旧图替代。
- `sheet_view.showGridLines = False`，`zoomScale = 80`。

### openpyxl 要点

```python
from openpyxl.drawing.image import Image as XLImage
from PIL import Image

im = Image.open(path)
img = XLImage(path)
img.width = 700
img.height = int(700 * im.size[1] / im.size[0])
ws.add_image(img, f"A{row}")
```

- 图片锚点用 `A4`、`J4` 这样的单元格坐标。
- 图片实际显示尺寸由 `img.width/height` 决定，不是原图像素。
- 删除占位合并单元格时先 `unmerge_cells`，再清空文字，再加图。

## 4. 颜色与字体

| 元素 | 色值 |
|---|---|
| 标题 | `#C00000` |
| 表头蓝 | `#2F5597` |
| 浅蓝标签 | `#D9EAF7` |
| 浅灰说明 | `#F2F2F2` |
| 边框 | `#BFBFBF` |
| 正增长 | 红（`[Red]`） |
| 负增长 | 绿（`[Green]`） |

字体统一 `微软雅黑`；标题 16pt，表头 10pt，数据 9pt，注释 9pt。

## 5. 行高参考

- 标题：34
- 表头：24–28
- 数据：20–22
- 空行：8
- 说明：26–30（自动换行）

## 6. 写入已有工作簿

- 先备份：`*_backup_before_<表名>_<YYYYMMDD_HHMM>.xlsx`。
- 新建 sheet 前检查是否已存在同名 sheet；存在则删除后重建，或改名追加，不能静默覆盖。
- `delete_rows()` 前先 `unmerge_cells()` 所有涉及行，否则会留下孤儿合并区域、`max_row` 虚高。
- 不覆盖其他 sheet。
