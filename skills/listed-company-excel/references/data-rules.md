# 数据口径与公司映射

## 1. 单季与累计

季报有两列：

- `本报告期`：单季；
- `年初至报告期末`：累计。

**单季计算**

```text
Q1 = Q1 累计
Q2 = H1 累计 − Q1 累计
Q3 = 9M 累计 − H1 累计
Q4 = FY − 9M 累计
```

**优先顺序**

1. 季报“本报告期”单季数；
2. 用累计差额复算，和单季数交叉核对；
3. 两者不一致时，以累计差额为准，并在表下注明差异。

## 2. 指标公式

| 指标 | 公式 |
|---|---|
| 毛利率 | 1 − 单季营业成本 / 单季营业收入 |
| 营收同比 | 单季营收 / 上年同季营收 − 1 |
| 扣非同比 | 单季扣非 / 上年同季扣非 − 1 |
| 扣非TTM | 最近四个单季扣非之和 |
| 净利率 | 单季归母净利 / 单季营业收入 |
| 有息负债 | 短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券 + 租赁负债 |

单位：

- 收入/利润：万元或百万元，全表一致；
- 比率：%；
- TTM：亿元（若原表为百万元，除以 100）。

## 3. 缺失与例外

- 未披露：写“—”，不写 0。
- 没有上年同季基数：同比列留空。
- TTM 不足四季：留空，不用零补。
- 公司上市晚：
  - 达利凯普：2023 年上市，2024Q1 起才有同比；
  - 宏明电子：2025 年起有季度收入，2026Q1 起才有同比；
  - 博迁新材：面板从 2021Q1 起，2022Q1 起才有同比。
- 风华高科没有现成季度面板时，用年报“分季度主要财务指标”取扣非，用季报/年报利润表累计收入、成本算单季毛利率。

## 4. 产业链分组与顺序

**上游 → 中游 → 下游**

- 按产业链位置排列，不把“粉/浆/MLCC”硬编码成通用分组；粉/浆/MLCC 只是 MLCC 链的具体叫法。
- 换一条产业链时，替换为那条链实际的上游/中游/下游环节。
- MLCC 场景的映射：
  - 上游 / 粉：博迁新材（金属粉体）、国瓷材料（陶瓷粉体，兼电子浆料）。
  - 中游 / 浆：A 股无纯浆料标的时，用一行说明；不要把海外公司（勤凯、大洲）放进 A 股表。
  - 下游 / MLCC：按已有 `MLCC` sheet 顺序，A 股子集：
  1. 风华高科（000636）
  2. 三环集团（300408）
  3. 达利凯普（301566）
  4. 鸿远电子（603267）
  5. 火炬电子（603678）
  6. 振华科技（000733）
  7. 宏明电子（301682）
  8. 宏达电子（300726）

海外公司（村田、三星电机、太阳诱电、TDK、国巨、宇阳、堺化学、大洲电子、勤凯科技）不进入“A 股单季同比”表；如确需保留，单独 sheet 并标注。

## 5. 从档案卡 / HTML 取数

- 档案卡：优先找第 2 节“长期财务序列”中的 `2026Q3（9M）`、`2026年1-9月`、`2026Q1-Q3` 行；没有单季行时，用累计差额拆单季。
- 分析 HTML：优先读同名 Markdown 源；HTML 只用于核对表头、单位、颜色，不直接从 HTML 表格抄数。
- HTML/Markdown 与季度面板不一致时，以定期报告原文为准，并修正下游产物。
- 档案卡里的“营收同比”通常是累计同比；单季同比要重新按单季营收计算，不能直接抄。

## 6. 数据来源优先级

1. `timeseries/季度财务面板.md` 表 A（单季营收/归母/扣非）和表 B（毛利率）；
2. `report/<公司>_档案卡.md` 的中期/季度行；
3. `report/<公司>.md` 或分析 HTML 的季度章节；
4. 定期报告原文（季报、半年报、年报）。

同一指标多处不一致时，以定期报告原文为准，并修正下游产物；不能只改 Excel。

## 7. 交叉核验示例

- 三环 2026Q3：单季营收 5,079.46；9M 11,502.80 − H1 6,423.33 = 5,079.47（尾差 0.01，四舍五入）。
- 国瓷 2026Q3：单季归母 182.65；9M 545.41 − H1 362.76 = 182.65。
- 博迁 2026Q3：单季扣非 89.95；9M 218.51 − H1 128.56 = 89.95。
- 扣非TTM：最近四季相加，不能拿年度扣非替代。

## 8. 表格注释模板

```text
口径：单季=累计数差额；同比=单季/上年同季-1；扣非TTM=最近四个单季扣非之和（亿元）。
2020 年同比因缺少 2019 年同季基数，整列留空。
达利凯普 2023 年上市、宏明电子 2025 年起有季度数据，之前留空。
分组：上游/粉（博迁、国瓷）→ 中游/浆（A股无纯浆料标的）→ 下游/MLCC（按 Excel MLCC sheet 顺序）。
来源：各公司定期报告及 timeseries/季度财务面板.md。
```
