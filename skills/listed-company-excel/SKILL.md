# 上市公司财务 Excel：单季营收同比与盈利质量

目标是把已有研究产物整理成两张可横向比较的季度表，以及一个 2×2 图墙 sheet；不重新研究公司，不做年度汇总表的增量维护。

## 适用与不适用

**适用**

- 已有各公司档案卡、分析 HTML/Markdown 或季度财务面板；
- 需要生成“单季营收同比矩阵”；
- 需要生成“单季盈利质量块”（毛利率、营收同比、扣非同比、扣非TTM）；
- 需要把各公司报告里的 2×2 季度面板图汇总到一个 Excel sheet；
- 需要按产业链**上游 → 中游 → 下游**分组；MLCC 场景细分为粉 → 浆 → MLCC；或按既有 Excel 顺序排列公司。

**不适用**

- 从零研究公司（用 `listed-company-research`）；
- 在年度汇总表右侧加新季度列（本 skill 不做这件事）；
- 估值模型、DCF、目标价；
- 没有底层数据、只凭记忆或行情编表。

## 输入与取数优先级

1. `timeseries/季度财务面板.md` 表 A（单季营收/归母/扣非）和表 B（毛利率）；
2. `report/<公司>_档案卡.md` 的中期/季度行；
3. `report/<公司>.md` 或分析 HTML 的季度章节；
4. 定期报告原文（季报、半年报、年报）。

**HTML 使用规则**

- HTML 是渲染产物，优先读它的 Markdown 源文件；
- 只在核对展示口径时读 HTML，不直接从 HTML 表格里抄数；
- HTML 与 Markdown/面板不一致时，以定期报告原文为准，并修正下游产物。

## 三种标准表

### A. 单季营收同比矩阵

结构（最新在左）：

```text
公司 | 26Q3 | 26Q2 | ... | 20Q1
上游（MLCC：粉）：
  博迁新材
  国瓷材料
中游（MLCC：浆）：
  （A 股无纯浆料标的时，用一行说明）
下游（MLCC：MLCC）：
  风华高科
  三环集团
  ...
```

**分组原则**：按产业链上中下游排列，不把“粉/浆/MLCC”硬编码成通用分组。粉/浆/MLCC 只是 MLCC 链的具体叫法；换一条产业链时，替换为那条链实际的上游/中游/下游环节。

规则：

- 数值 = 单季营收 / 上年同季营收 − 1，单位 %。
- 季度范围默认 2020Q1–2026Q3；也可按模板只做 2022Q4–2026Q3。
- 2020 年同比需要 2019 年同季基数；没有就整列留空，并在表下注明。
- 公司间用空行分组；表头蓝底白字；正增长红色、负增长绿色。
- 冻结首列和表头；季度列宽 7–8，公司列宽 14–18。

### B. 单季盈利质量块

每家公司 5 行：

```text
公司名（代码） | 26Q3 | 26Q2 | ... | 22Q4
毛利率
营收同比
扣非同比
扣非TTM（亿元）
（空行）
```

规则：

- 毛利率 = 1 − 单季营业成本 / 单季营业收入。
- 营收同比 = 单季营收 / 上年同季 − 1。
- 扣非同比 = 单季扣非 / 上年同季 − 1。
- 扣非TTM = 最近四个单季扣非之和；单位亿元时除以 100（若原表为百万元）。
- TTM 必须连续四季；缺一季就留空，不用零补。
- 每家公司一个蓝色标题行，下面 4 行指标，公司之间空一行。
- 毛利率、扣非TTM 用黑色；营收同比、扣非同比用红/绿。

### C. 2×2 季度面板图墙

结构：

```text
标题
上游｜粉
  博迁新材       国瓷材料
  [图]            [图]
中游｜浆
  （说明行）
下游｜MLCC
  风华高科       三环集团
  [图]            [图]
  ...
```

规则：

- 图来自各公司 `report/charts/quarterly_panel.png`（报告 HTML 里的 2×2 面板）。
- 按产业链**上游 → 中游 → 下游**、两列 × N 行排列；同一行从左到右，行与行从上到下保持顺序。
- 每张图上方一行公司名（含代码），图下方留白或空行。
- 某公司没有图时，放灰色占位说明，**不要拿旧图或其他公司图替代**。
- 图宽约 700px，等比缩放；图所在行行高约 390pt；左图放 `A:H`，右图放 `J:Q`，中间 `I` 列留 3 字符间隔。
- 隐藏网格线，缩放 80%。
- 如报告目录没有 `quarterly_panel.png`，先按 `listed-company-research` 的季度图规范生成，再插入；生成不了就写占位。

## 生成流程

### 1. 确认范围

- 公司清单与分组（上游/中游/下游；MLCC 场景为粉/浆/MLCC）；
- 下游内部顺序是否按既有 Excel sheet（MLCC 场景即 MLCC 公司顺序）；
- 季度范围与方向（最新在左/右）；
- 是否只要其中一张表、两张都做，还是加一个 2×2 图墙 sheet。

### 2. 备份

如写入已有工作簿，先复制为 `*_backup_before_<表名>_<YYYYMMDD_HHMM>.xlsx`。新建工作簿可跳过。

### 3. 提取单季序列

- 先读 `timeseries/季度财务面板.md` 表 A/表 B；
- 没有面板时，读档案卡季度行、报告 md 的季度章节；
- 单季 = 本期累计 − 上期累计：
  - Q1 = Q1 累计；
  - Q2 = H1 − Q1；
  - Q3 = 9M − H1；
  - Q4 = FY − 9M。
- 毛利率用单季收入/成本计算；不要用累计毛利率代替。
- 扣非TTM 用单季扣非相加；不要用年度扣非代替。

### 4. 计算

| 指标 | 公式 |
|---|---|
| 单季营收同比 | 单季营收 / 上年同季营收 − 1 |
| 单季毛利率 | 1 − 单季营业成本 / 单季营业收入 |
| 单季扣非同比 | 单季扣非 / 上年同季扣非 − 1 |
| 扣非TTM | 最近四个单季扣非之和 |

### 5. 写入

- 营收同比矩阵：最新季度在左；缺值留空；正负用数字格式着色。
- 盈利质量块：按公司块写入；块间空行；标题行蓝底。
- 表下加注释：口径、单位、缺数原因、来源。

### 6. 验收

至少检查：

1. 表头季度顺序是否正确。
2. 单季 = 累计差额；抽查 3 家公司 × 2 个季度。
3. 毛利率 = 1 − 成本/收入；抽查 3 个值。
4. 扣非TTM = 最近四季之和；抽查 2 家。
5. 同一指标在 Excel、季度面板、档案卡三处是否一致。
6. 没有把 9M 累计填进“单季”列。
7. 没有覆盖历史列/行。
8. 合并单元格没有残留（尤其是 `delete_rows` 之后）。
9. 图墙：图片数量、公司顺序、占位说明是否正确。

## 数据口径

- 不编造、不倒推、不用相邻期间填补；未披露写“—”。
- 只放 A 股公司；海外公司不进入 A 股同比表。
- 公司顺序：**上游 → 中游 → 下游**；MLCC 场景细分为粉 → 浆 → MLCC；下游内部按既有 sheet 顺序，不按市值/涨幅重排。
- 达利凯普 2023 年上市，2024Q1 起才有同比；宏明电子 2025 年起有季度收入，2026Q1 起才有同比。
- 风华高科没有现成季度面板时，用年报“分季度主要财务指标”取扣非，用季报/年报利润表累计收入、成本算单季毛利率。

## 格式规范

| 元素 | 规范 |
|---|---|
| 标题 | 微软雅黑 16pt，加粗，深红 `#C00000`，合并居中 |
| 表头 | 填充 `#2F5597`，白色 10pt 加粗，居中 |
| 指标标签列 | 填充 `#D9EAF7`，9–10pt |
| 边框 | 细线 `#BFBFBF` |
| 正增长 | 红色（数字格式 `[Red]`） |
| 负增长 | 绿色（数字格式 `[Green]`） |
| 百分比 | `0.00"%"` 或 `0.0"%"` |
| 亿元 | `0.00"亿"` |
| 空值 | 空单元格或“—”，不写 0 |
| 冻结 | 矩阵表冻结首列+表头；块状表冻结首列 |
| 行高 | 标题 32–36；表头 24–28；数据 20–22；空行 8 |

数字格式示例：

```text
毛利率：0.00"%"
同比：[Red]0.00"%";[Green]-0.00"%";0.00"%"
TTM：0.00"亿"
```

## 常见坑

- **单季/累计混用**：三季报的“年初至报告期末”是 9M，不是 Q3 单季；单季要用 9M − H1。
- **2020 年同比**：没有 2019 年同季基数时留空，不要用年度增速代替。
- **TTM 缺季**：少一季就留空，不要用零或更早季度补。
- **扣非 vs 归母**：扣非同比、扣非TTM 只用扣非；不要拿归母替代。
- **合并单元格**：`openpyxl.delete_rows()` 不会自动清理合并区域，删行后要手动 `unmerge` 再删。
- **数字格式颜色**：用 `[Red]`/`[Green]` 数字格式即可，不必逐个设置字体颜色。
- **公式**：`data_only=True` 读不到未计算公式；表内尽量写值，不写公式。
- **HTML 抄数**：HTML 只作核对，优先读 Markdown/面板/原文。
- **A 股边界**：海外公司（村田、三星、太阳诱电、TDK、国巨、宇阳、堺化学、大洲、勤凯）不进入 A 股同比表。
- **公司起点**：达利 2023 年上市、宏明 2025 年起有季度数据；早期留空，并在表下注明。
