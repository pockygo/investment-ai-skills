## 1. 章节映射

| 源材料内容 | Word 目标章节 |
|---|---|
| 项目概览、公司简介、投资条款 | 投资概要 |
| 投资亮点、已完成里程碑 | 投资亮点分析 |
| 亏损、客户集中、供应链依赖、竞业、验证进度 | 投资风险分析 |
| 行业定义、工艺环节、产业链 | 行业概况/行业介绍 |
| 市场规模、周期、产能、国产化率 | 行业概况/市场规模与驱动因素 |
| 国内外竞争对手及财务数据 | 行业概况/竞争格局 |
| 公司设立、注册资本、地址、实控人 | 公司情况 |
| 历史融资、股东明细、员工持股平台 | 股权结构及融资情况 |
| 组织架构、人员数量 | 公司情况或团队和管理 |
| 核心团队履历 | 团队和管理；逐人完整保留 |
| 产品介绍、价格、产能 | 产品、技术与业务 |
| 工艺步骤、专利、路线图、国产化计划 | 产品与技术 |
| 订单、客户、在验证/在开发产品 | 业务进展 |
| 资产负债表、利润表、现金流量表 | 财务分析 |
| 盈利预测、估值比较、敏感性测算 | 盈利预测与估值 |
| 投资主体、金额、估值、交易结构 | 投资方案 |
| 上市、并购、回购、清算等 | 退出安排及保障条款 |

## 2. 文本保真

- 保留公司名、人名、日期、金额、单位、产品型号、技术缩写和资料来源。
- 对源材料中的换行断词进行合并，但不改写专业含义。
- 团队履历按“姓名/职务—教育—工作经历—成果”组织；不得只保留一句总结。
- 对同一事实存在不同口径时，不擅自统一；在相邻位置并列原始口径并提示需核实。
- 不将 PPT 标题如“项目分析”“投决事项”写成“报告中提到”。只保留适合投资建议书的语义标题。

## 3. 表格处理

- 每个 PPT 原生表格建立来源页、目标章节、行列数和完成状态。
- 合并单元格可在 Word 中恢复；若恢复会影响跨页稳定性，可重复标签但不得丢数据。
- 超宽资产负债表拆为“资产”和“负债及所有者权益”。
- 超宽现金流量表拆为“经营活动”“投资活动”“筹资活动”。
- 订单表保留客户、产品、金额、数量、日期、付款条件及合计。
- 表格跨页时重复首行；数值列居中或右对齐，叙述列左对齐。
- 表头白底黑字；正文不使用彩色字体。

## 4. 图片选择

优先插入：

- 产品实物照片；
- 设备及生产线照片；
- 产品结构、工艺流程和技术路线图；
- 市场规模、价格周期、产能变化图；
- 组织架构图；
- 原生表格无法表达的仿真、检测或显微结果。

不插入：

- 目录页；
- 只有文字和表格的整页截图；
- 重复的装饰性图片；
- 分辨率不足且没有信息增量的图片。

## 5. 风险与缺失信息

- 风险章节只能从源事实推导：尚未盈利、客户集中、关键部件外协、核心人员未到岗、竞业限制、产品验证、估值假设等。
- 清楚区分事实与推导，避免使用确定性结论描述尚未实现的预测。
- 源材料未提供的退出、对赌、知识产权或合规信息用“—”或“未列示”，不得编造常规条款。

## 6. 覆盖清单

为每页/每张幻灯片至少记录：

| 页码 | 标题 | 正文目标章节 | 表格状态 | 图片状态 | 备注 |
|---|---|---|---|---|---|
| 1 | 封面 | 封面日期/主体 | 不适用 | 通常不采用 | 保留内容日期 |
| n | 财务状况 | 财务分析 | 已重建 | 不采用整页 | 检查合计与负数 |

只有当全部源页均有明确去向或明确“不采用”理由时，才进入生成阶段。
