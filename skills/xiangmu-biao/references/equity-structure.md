# 第八区「最新股权结构」维护规则（项目表.xlsx）

本文件是 `SKILL.md` 第 9 条的展开。2026-09-22 依据当时的项目表实况（13 个 sheet、8 个已建八区）整理，含真实案例与数值证据。

## 1. 区块定位与列规格

- **位置**：一律在**第七区（IRR计算）之后、sheet 表尾**。这是全表唯一「追加即安全」的区块：七区及以上所有单元格与公式引用都不受影响（实测八区落地后 ①–⑦ 区与旧版逐格 diff = 0 差异，全部 121 个公式没有一个引用八区行）。**绝不可插到七区之前**；确需如此必须先走 `openpyxl-recipes.md` 的 `fix_formulas` + `shift_down`。
- **占列**：只用 A、B、C 三列。**不要用 D 列及以后**（④区在 M/N、佰澳达在 N/O 有零散测算列），**不要改列宽**（列宽是全表共享属性，改 A/C 会牵连①区标签、②区基金名称、③区金额列的显示）。
- **分隔**：标题行前留 1 行空白（与其他区块间距一致）。
- **行结构**：标题行（合并 A:L）→ 表头行（单行）→ 可选注释行（来源/基准日/口径）→ 股东明细行（按比例降序）→ 合计行。

| 列 | 表头 | 内容 | 数字格式 | 对齐 |
|---|---|---|---|---|
| A | 股东（发起人） | 股东全称（与工商登记一致） | General | 左对齐、`wrap_text=True` |
| B | 持股比例 | 数值（非字符串） | `0.0000%` | 右对齐/居中 |
| C | 认缴出资额（万元） | 数值（万元） | `#,##0.00` | 右对齐/居中 |

- **股份公司**用股本口径，C 列表头改「**持股数（万股）**」（奥派装备、康瑞新材）。与②区「股份公司与有限公司统一按注册资本（万元）口径」一致。
- 标题行样式与其他区块完全相同：11 号加粗白字、深蓝底 `2F5597`、整行合并 A:L；表头 10 号加粗、浅蓝底 `D9E1F2`、居中换行、细边框 `999999`；正文微软雅黑 10；注释 9 号灰字。
- 合计行：A 写「合计」，B/C 用 `=SUM()`（**禁止写死数值**），橙底 `FCE4D6` 加粗。

可直接复用的样式常量：

```python
HEADER_FONT = dict(name='微软雅黑', size=10, bold=True)
BODY_FONT   = dict(name='微软雅黑', size=10)
TITLE_FILL  = '2F5597'      # 区块标题（白字）
```

## 2. 数据来源与提取

优先级：**最新工商股东名册 / cap table**（附基准日）> 投决报告「股权结构」页（须注明为报告基准日）> 老股东名册（须核对是否早于最新融资轮次）。**不得用旧股权表冒充最新名册**。

三种来源的提取路径：

- **.docx 股东名册**（如《励楷科技股东.docx》）：`python-docx` 读 `Document(SRC).tables[0]`，逐行取「股东名称 / 出资额 / 持股比例 / 出资方式 / 出资时间」；末行常为「合计」给出公司注册资本。
- **.xlsx 名册**：openpyxl `data_only=True` 读，注意有的名册已经是「按股东合并」后的三列（股东名称｜持股比例｜持有注册资本数）。
- **扫描件/PDF**：fitz 3 倍矩阵渲染 PNG → 逐页读 → 关键单元格裁切放大核对，再用「各行出资额求和 = 注册资本」勾稽。

**同一股东多笔出资必须合并为一行**（不同出资方式或出资时间）：

```python
from collections import OrderedDict
from decimal import Decimal as D

groups = OrderedDict()
for name, amt in raw_rows:                 # raw_rows: (股东, 出资额万元)
    groups.setdefault(name, D(0))
    groups[name] += D(str(amt))
CAP = sum(groups.values(), D(0))           # 与一区 C16 比对
rows = [(n, amt / CAP, amt) for n, amt in groups.items()]   # 比例 = 合计出资 / 注册资本
rows.sort(key=lambda x: -x[1])             # 按比例降序
```

要点：金额一律用 `Decimal`（不要 float 累加，避免 20.211→20.221 之类的尾差）；比例由「合计出资 ÷ 注册资本」算出，**不要直接抄名册里的比例列**（名册常有四舍五入残留，ΣB 会偏离 100%）。

## 3. 写入

优先用自带脚本（默认 dry-run，`--write` 才落盘）：

```bash
PYTHONIOENCODING=utf-8 python scripts/build_equity_block.py \
  --workbook 项目表.xlsx --sheet 康瑞新材 \
  --register "康瑞新材股东名册/康瑞新材-股东名册.xlsx" \
  --base-date 2026-09-20 --note "来源：工商股东名册" --write
```

脚本行为：读名册 → 合并同名股东 → 降序 → **追加**到 sheet 表尾（标题前留 1 空行）→ 写标题/表头/注释/明细/合计行并套用规范样式 → 打印 ΣB、ΣC 与一区 C16 的差值。八区已存在时拒绝执行（除非 `--replace`）。

手工写入时遵守：

1. 先备份 `cp 项目表.xlsx 项目表_backup_YYYYMMDD.xlsx`。
2. `start = ws.max_row + 2`（末行之后空一行），标题 `ws.merge_cells(start_row=start, start_column=1, end_row=start, end_column=12)`。
3. 写日期用 `datetime.date` + `number_format='yyyy/m/d'`（本区一般无日期，但注释里的基准日写文本 `YYYY-MM-DD`）。
4. 明细行的 A 列务必 `wrap_text=True`（历史八区多为 False，长股东名显示不全）。
5. 写后必须跑 `scripts/validate_workbook.py` 回读。

## 4. 三条勾稽（写入前必算、写入后回读）

1. **ΣC（认缴出资额合计）= 一区「注册资本（万元）」C16** —— 一区该行的标签在 A:B（合并），值在 C:L（合并），注册资本的**数值**在 `C16`；不要硬编码行号，按标签「注册资本」查找更稳。
2. **ΣB（持股比例合计）= 100%** —— 允许 ±0.0001% 的四舍五入残留，超出即为数据错误。
3. **我方基金持股与②区「当前持股比例」一致** —— ②区是穿透口径、八区是名册口径；八区出现我方基金的 SPV 行（而非我方基金本身）属正常，必须能对上「SPV 持股 × 我方在 SPV 的份额」。

```python
# 勾稽片段（金额用 Decimal，比例容差 1e-6）
reg = 一区注册资本(ws)                        # 按标签取
sum_c, sum_b = sum(amounts), sum(pcts)
assert abs(sum_c - reg) < 0.005,  f'ΣC={sum_c} vs C16={reg}'
assert abs(sum_b - 1) < 1e-5,     f'ΣB={sum_b}'
```

## 5. 四类常见错误与真实案例（2026-09-22 实测）

| 案例 | 现象 | 证据 | 处置 |
|---|---|---|---|
| 蔚谱光电 | 八区 C61 写 **20.221**，应为 **20.211** | ②区=20.211、C16=404.211；ΣC=404.221（差 +0.01）；B61=5.0001% 本身是对的（=20.211/404.211） | 单笔小数笔误，直接改 C 值；属唯一可立即修正的一类 |
| 数字光芯 | ΣC=**167.484** ≠ C16=**165.564251**（差 +1.919749）；八区自洽（1.8408/167.484=1.0991%）但②区 J24=**1.1112%** | 八区像是最新一轮后名册，①区/②区未同步 | 先确认是否存在新轮次/期权池；若名册为准 → 改 C16 与②区 J，并复核④区剩余估值与⑦区 XIRR 现金流 |
| 诺宇医药 | C16=**6480** vs ΣC=**6390**（差 −90）；②区按 6390 计算且与八区完全一致 | ①区注册资本疑似漏更新 | 若 6390 为登记口径 → 改 C16；同时检查③区「投后公司注册资本」 |
| 篆芯半导体 | 八区**没有**我方基金行，只有 SPV「苏州隆湫云芯」（108.7599 万 = 5.4292%） | ②区按穿透列 合创二期/三期各 0.5715%，合计 1.1430%；108.7599/2003.2511=5.42917% | 正常口径差，**不改数**，在八区注释写明穿透对应关系 |

补充：晋成 ΣB=99.9998%、盛欣科 ΣB=100.0001%（四舍五入残留，正常）；篆芯 ΣC 比 C16 高 0.000058 万（名册高精度 vs ①区截断，正常）。

**ΣC ≠ C16 的三条成因与判定顺序**（不要先改①区）：

1. **登记口径已更新**（新轮次增资/期权池/注册资本变更）→ 应更新①区 C16，并联动②区「投后公司注册资本／当前持股比例」、④区剩余估值、⑦区 XCF 行。
2. **名册是增资前口径**（基准日早于最新轮次）→ 应换名册，不改表。
3. **笔误/漏股东**（单笔小数错、名册漏列某股东）→ 修正该笔（蔚谱案例）。

## 8. 交付前检查清单

1. `scripts/validate_workbook.py --workbook 项目表.xlsx` 无 ERROR（WARN 逐条解释）。
2. ΣC = C16、ΣB = 100%、我方基金两口径能对上或已注释说明。
3. 样式合规：单行表头、微软雅黑 10、细边框、B `0.0000%`、C `#,##0.00`、A 列换行、合计行橙底 + `=SUM()`。
4. ①–⑦ 区未被触碰（与改前 diff 应为 0 差异）。
5. 备份文件与更新脚本路径写进交付报告。
