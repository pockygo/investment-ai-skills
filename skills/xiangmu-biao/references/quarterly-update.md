# 季度财报补录工作流（第六区经营情况跟踪）

适用于「用 XXQn报表 文件夹更新各公司季度数据」这类批量任务。2026Q2 批量更新（9 家公司）验证通过。

## 1. 盘点

- 列出报表文件夹内容，按文件名前缀映射到公司 sheet 名；注意有的公司可能缺本期报表（不补、不催，交付时说明），有的季度行可能已存在（见下）。
- 读取项目表每个目标 sheet 的六区：确认最后一个已录季度、定位新行写入位置、检查目标季度是否已录入（**已存在则只核对数值，不重复写**——佰澳达 2026Q2 案例）。

## 2. 数据提取（按文件类型分流）

先对每份 PDF 用 fitz 测文本量（`sum(len(p.get_text()))`），据此分流：

- **文本型 PDF**（文本量 > 数千字符）：直接 `get_text()` 提取，自己读。
- **扫描件 PDF**（文本量 ≈ 0，通常文件较大）：派子代理并行提取，每家公司一个子代理。要求子代理：fitz 以 3 倍矩阵渲染 PNG → ReadMediaFile 逐页读 → 关键单元格 region 裁切放大核对 → 返回万元口径数据 + 勾稽验证结果 + 口径（合并/单体）+ 币种。临时图片文件夹用后删除。
- **xlsx 财报**：openpyxl `data_only=True` 直接读各 sheet。

每家公司需提取的 8 项（万元，保留两位小数；报表单位为元则 ÷10000）：

- 资产负债表（期末）：货币资金、总资产、净资产（所有者权益合计，含少数股东权益）
- 利润表（当年累计）：营业收入、营业成本（算毛利率用）、净利润
- 现金流量表（当年累计，如有）：经营性现金流净额、现金及现金等价物净增加额

## 3. 列口径判定（税务季报陷阱）

税务系统/财务软件导出的季度报表列名不统一，常见三种：

- 「期末余额 / 年初余额」（资产负债表）→ 取期末
- 「本期金额 / 本年金额（本年累计）/ 上期金额」三列（现金流量表、利润表）→ **取累计列**
- 「本月数（发生额）/ 本年累计数」两列 → 取本年累计

「本期金额」可能是本季度单季而非累计，判定方法：

- 现金流量表：累计列的「期初现金及现金等价物余额」= 年初数（= 上年 Q4 货币资金，注意现金等价物可能含交易性金融资产，与货币资金有小额差异属正常）
- 利润表：「上期金额」与台账中上年同期累计数比对（晋成案例：报表上期净利 -809.62 万 ≈ 台账 2025Q2 累计 -807.64 万，证明本期=当年累计）

扫描件可能标题标错（佰澳达案例：利润表标题 2026-03-31 但数值是半年累计）——用相邻季度数据的量级关系交叉验证（半年累计营收应 ≈ Q1 的 2 倍而非相等），存疑时在交付说明中提示用户向公司核实。

## 4. 勾稽验证（必做）

- 资产总计 = 负债合计 + 所有者权益合计
- 现金净增加额 = 经营 + 投资 + 筹资（+ 汇率影响）净额之和
- 期初现金 + 净增加 = 期末现金，且期末现金 ≈ 资产负债表货币资金
- 与上一季度趋势比对：净资产变动 ≈ 当季净利润 ± 增资（大额差异在交付中说明原因，如增资、可转债转股）

对不上的数字重新裁切放大核对，仍对不上如实标注，不得猜测填入。

## 5. 写入

- 毛利率自行计算 =(营收-成本)/营收，取 4 位小数（如 0.1845），单元格格式 0.00%；成本为 0 按惯例填 1 并在注释说明；营收为 0 留空。
- 无现金流量表的公司（如奥派单体报表）现金流两列留空，数据来源列注明「无现金流量表」。
- 数据来源列沿用该公司既有命名风格（如「202606财务报表」「2026Q2财报（合并口径）」「202606集团合并报表」）。
- 口径变化更新表下注释（如奥派注释补「2026Q1/Q2为单体」）。
- **插入位置**：优先用既有空白行（先解除空白行可能存在的整行合并）；无空白行则在最后季度行之后、注释行之前插行，用 `references/openpyxl-recipes.md` 的移位算法把注释+七区整体下移一行。禁止 insert_rows。
- 新行样式整体复制自上一个季度行（边框/数字格式/字体随行而来），日期一律短日期 `yyyy/m/d`。

## 6. 写后校验清单

1. 回读每个改动 sheet 六区至表尾的全部非空单元格：新行数值正确、注释和七区下移到位、无覆盖错位。
2. 回读全部公式单元格：四区 IRR 引用（如 `=B65`→`=B66`）、XIRR 区间（如 `XIRR(B63:B64,...)`→`B64:B65`）、七区引用四区的 `=J37` 类公式（行号 < 插入点，应不变）。
3. 抽查新行样式：细边框、`#,##0.00`、`0.00%`、微软雅黑 10。
4. 抽查合并单元格：区块标题、注释行合并区域随移位同步，无残留旧合并。
5. **八区勾稽（有八区的 sheet 必跑）**：Σ认缴出资额 = 一区「注册资本（万元）」C16、Σ持股比例 = 100%、我方基金八区持股与②区「当前持股比例」一致（经他人管理 SPV 的按穿透口径说明）。可直接跑 `scripts/validate_workbook.py`。
6. **注册资本联动**：本期若涉及增资、可转债转股、老股转让或期权池变动，八区的股东行与比例必须同步刷新（并更新注释里的名册基准日），同时检查①区 C16、②区「投后公司注册资本／当前持股比例」、③区投后注册资本、④区剩余估值、⑦区 XCF 行是否需同步——拿不准的一律列入交付报告的「联动待确认」。

## 7. 交付报告

- 列表给出每家公司核心数据（货币资金/总资产/净资产/营收/净利/毛利率）。
- 明确提示：报表异常（标题错、缺表现金流量表）、财务风险信号（净资产逼近 0、货币资金极低、大额亏损）、口径变化、未提供财报的公司、注册资本变动等本次未覆盖的联动事项（如②③区、八区股权结构是否需同步更新，提示用户决定）。
- 说明备份文件位置与更新脚本名。
