# 项目表维护规则（投资项目投后台账）

## 工作环境

- 工作目录：优先使用用户明确提供的项目表和材料路径；不得假设固定操作系统、用户名或桌面目录。未提供目标文件时，先在当前工作区及用户提到的项目文件夹中查找 `项目表.xlsx`，仍无法确定再询问用户。
- `投资项目汇总表.xlsx`：数据源。Sheet1 第 4 行为表头（58 列），一行 = 一个基金的一笔投资；同一家公司可能出现多行（不同基金/轮次），用「投资项目名称」匹配。公司级字段（行业、赛道、注册地等）各基金行一致，投资/退出字段按基金行区分。
- `项目表.xlsx`：维护目标。每个被投公司一个 sheet，sheet 名 = 公司简称（如「晋成半导体」）。
- `<公司简称>/` 文件夹：每家公司的财报（.xls/.xlsx）、投决报告（.pptx）等原始材料。
- 模板参考：「晋成半导体」sheet；生成脚本 `_build_jincheng.py`（结构示例，新公司复制改数据）。

## 技术要点

- Python + openpyxl 读写 xlsx；.xls 老格式用 pandas.read_excel。
- Windows 控制台必须 `PYTHONIOENCODING=utf-8 python`，否则中文乱码。
- **批量修改前先备份**：`cp 项目表.xlsx 项目表_backup_YYYYMMDD.xlsx`。
- **禁止 insert_rows / 删行移动单元格**：表内有跨区公式引用（如 `I36=H58`、XIRR 区），移动行会破坏引用。要加行就就地重写固定行区域的内容和样式——标准移位算法（公式引用行号修正、合并单元格同步、样式复制）见 `references/openpyxl-recipes.md`。
- 含正则/多步逻辑的脚本**写入 .py 文件再执行**，不要 `python -c "..."` 内联——bash 双引号会吞掉 `\$`、`\d` 等反斜杠，正则静默失效且不易察觉。
- 改完必须回读校验：打印全表非空单元格 + 所有公式单元格，确认内容和公式引用无误。校验清单见 `references/quarterly-update.md`。

## Sheet 结构（七个区块，A:L 共 12 列网格）

1. **标题区**：A1 公司名+「项目情况表」；A2 移交公司 + 数据截止日 + 单位说明（金额除标注外均为万元）。
2. **一、项目基本信息**：键值对（标签 A:B 合并，值 C:L 合并）。含项目名称、投资主体（多基金用；分隔）、投后负责人、项目组成员、公司简介、行业/赛道/465、工商信息、无锡项目/招引、高新/专精特新、上市进度。其中「注册资本（万元）」填数值（最新实际注册资本），不带文字说明。公司简介 ≤350 字，素材取自投决报告（主营、行业地位、团队、客户、竞争优势、最新业绩）。
3. **二、投资明细（分基金/分轮次）**：注册资本口径，一行一个基金。列：基金名称｜投资轮次｜首笔投资时间｜实际出资｜获得注册资本（万元）｜投后公司注册资本（万元）｜该轮每股注册资本单价（元）｜原始持股比例｜当前持有注册资本（万元）｜当前持股比例｜投资时投后估值（亿元）｜是否领投。每股单价 = 实际出资 / 获得注册资本（增资+老股组合时可按增资价口径，以用户调整为准）；持股比例 = 注册资本 / 公司注册资本；部分退出的基金「当前持有注册资本」小于「获得注册资本」。**股份公司与有限公司统一按注册资本（万元）口径**，股份公司即股本/万股（奥派案例：总股本 4,010 万股填 4,010）。末行合计：出资额直接求和，持股用 `=SUM()` 公式。
4. **三、公司融资历程**：公司视角，一行一轮。列：时间｜投前估值(亿)｜融资金额(亿)｜投后估值(亿)｜参与机构（各机构后括号注金额，万元）｜投后公司注册资本（万元）｜该轮每股注册资本单价（元）（后两列能算则填， unknown 留空）。
5. **四、退出与收益**：一行一个基金，公式化。列：基金名称｜退出阶段｜退出日期｜退出注册资本｜已退总额(含分红)｜已退本金｜退出收益｜项目分红/其他收益｜IRR｜剩余在投项目估值｜MOIC。规则：
   - 剩余在投估值 = 当前持有注册资本 × 最新一轮每股单价（公式引用②或③区的单价单元格，如 `=I24*G33`；若最新轮单价与我方成本不同，用最新轮价）
   - 部分退出：已退总额/已退本金按实际收款填（可与协议计划不同），退出注册资本填已交割部分，当前持有 = 获得 − 已退出；退出收益可用公式 `=E-F`
   - MOIC：在投 `=J/D`；部分退出 `=(J+E)/D`
   - IRR 引用第七区 XIRR 结果（如 `=B58`），不写死数值；**完全退出的项目 IRR 按汇总表口径填定值并用蓝色字体**（佰澳达案例）
6. **五、协议与风控**：一行一个基金，同一轮投资的基金条款相同。列：基金名称｜协议是否约定退出方式｜协议退出期｜协议退出方式｜是否有回购条款｜回购约定时间｜是否触发｜若有后续安排｜是否存在损失风险｜是否属于风险项目。
7. **六、经营情况跟踪（季度）**：一行一季度，**公司提供哪个季度的财报就写哪个季度，全部列出**（如提供了 2023-2026 各季度，就从 2023Q3 写到 2026Q1），不要只写最近几期。列：期间｜货币资金｜总资产｜净资产｜营业收入｜净利润｜毛利率｜经营性现金流净额｜现金净增加额｜数据来源。规则：
   - 单位万元；资产负债表科目为期末时点数；利润表、现金流量表为**当年累计数**（报表本身是累计口径，直接取累计列）
   - 毛利率 = (营业收入-营业成本)/营业收入，自行计算；营收为 0 时留空
   - 该期财报无现金流量表则现金流两列留空，数据来源列注明「无现金流量表」
   - 数据来源注明财报文件名/期间；合并/单体口径变化、不同会计准则差异在数据来源列和表下注释说明
   - 扫描件 PDF：用 fitz 渲染成图片后逐页阅读，关键单元格裁切放大核对，并用「期初现金+净增加≈期末现金」「资产≈负债+权益」勾稽验证；量大时可派子代理并行提取（每家公司一个子代理，要求返回万元口径数据+勾稽结果）
   - 年度财报按 Q4 行填列；非标准期间（1-2月、1-4月等）期间列写实（如 2026M1-2）
   - **写入前先检查该季度行是否已存在**（用户可能已手动录过，如佰澳达 2026Q2 案例）——已存在则只核对数值不重复写入
   - **税务季报陷阱**：税务系统导出的季度报表常有「本期金额/本年金额（或本年累计）/上期金额」三列，「本期」可能指本季度而非累计——必须取累计列。用「上期金额」与台账历史数据比对可判定列口径（晋成 2026Q2 案例：上期净利 ≈ 台账 2025Q2 累计净利，证明本期=当年累计）；现金流量表看「期初现金余额」是否等于年初数来确认
   - 扫描件标题可能标错（佰澳达案例：利润表标题写 3 月 31 日但数值是半年累计）——用相邻季度数据交叉验证量级，发现异常在交付说明中提示用户
8. **七、IRR计算**：每只基金一组（日期列+金额列），按实缴/退出逐笔记现金流（负数=出资，正数=回款），期末行 = 数据截止日 + 剩余在投估值（引用第四区），末行 `=XIRR(金额区域,日期区域)`。
   - 刚交割（持有未满一月）或出资日与截止日同日的，XIRR 年化无意义甚至报错——用 `=IFERROR(XIRR(...),"—")` 防护并加注，待实际打款日确定后更新
   - 出资/退出日期以协议、出资证明、打款凭证为准；无凭证时按投决日/决议日暂列并加注

## 样式规范

- 字体微软雅黑：标题 16 加粗居中；区块标题 11 加粗白字、深蓝底（2F5597）、整行合并 A:L；表头 10 加粗、浅蓝底（D9E1F2）、居中换行；正文 10；注释 9 灰色。
- 所有表格单元格细边框（999999）；金额格式 `#,##0.00`；百分比 `0.00%`；**日期一律用短日期格式 `yyyy/m/d`**（显示为 2026/6/30），不要用 `yyyy-mm-dd` 等长日期格式。
- 合计行橙底（FCE4D6）加粗。

## 新增公司 sheet 的工作流

1. 汇总表中按公司名称筛出所有基金行，提取投资/退出/风控字段。**新项目可能尚未纳入汇总表**（如数字光芯、诺宇、富锂盈）——此时直接按公司文件夹材料（投决报告、增资/股东协议、cap table、出资证明）建表，并在②区注释标明「暂未纳入汇总表」。
2. 读该公司文件夹：投决报告（公司简介、融资历程、股权结构、每股单价）、各期财报（第六区数据）。无单独财报时，可用投决报告披露的财务报表（通常年度+最近一期），数据来源列注明「投决报告」。
3. 复制「晋成半导体」结构生成新 sheet（可改 `_build_jincheng.py`），填数、写公式。
4. 回读校验内容与公式，向用户报告数据缺口（如缺某期现金流量表）。

## 数据纪律

- SPV 处理看管理人归属：SPV 由我们（和合）管理的（如江阴高新合励），按 SPV 基金本体口径记录（全额出资、全部注册资本），不穿透，可在注释中注明我方基金的出资构成；若只是我们参与出资、由他人管理的 SPV（如苏州隆湫云芯、无锡诺合耀宇），则必须穿透到我方基金的实际出资额和对应注册资本/持股记录。
- **投资主体名称冲突时以最新法律文件为准**：投委会决议/增资协议 > 投决报告（富锂盈案例：2025-05 增资协议写澄创一期，2026-06 决议写港联星程，按决议建表并标注待确认）。
- 增资+老股组合交易：②每股单价按综合成本（实际出资/获得注册资本），③记录各轮增资价与老股价，④剩余估值按最新一轮**增资价**计算（数字光芯、盛欣科案例）。
- 汇总表与投决报告/协议/股权表不一致时（如退出日期、佰澳达「完全退出」与 2025-01 股权表 8% 持股矛盾），按汇总表建表，但在注释中用 ⚠ 写明冲突证据，向用户提示确认。
- 汇总表中可疑数值（如在投项目 IRR 异常）原样搬入后必须向用户提示核对。
- 不擅自修改用户已调整过的结构；用户手动更新模板后，先重读理解新格式再操作。**向已有 sheet 追加行前先核对目标行的现有内容**（用户可能已删除/插入行导致行号漂移），写错行会覆盖数据。
