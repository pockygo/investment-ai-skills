# 固定报告框架与分析规则

## 一、固定六章

一级章节必须依次为：

1. 一、财务尽调背景情况
2. 二、主要尽调事项
3. 三、财务报表情况
4. 四、利润表明细情况
5. 五、资产负债表明细情况
6. 六、财务尽调发现的主要问题及风险揭示

### 第一章：财务尽调背景情况

说明目标公司、简称、尽调基准日、覆盖期间、审阅范围、第三方机构与报告、资料限制及金额单位。仅有三方报告时，不得声称内部团队已完成现场盘点、函证或穿行测试。

### 第二章：主要尽调事项

固定顺序：

1. （一）收入及利润变动情况
   - 1、标的公司主要损益数据情况
   - 2、收入变动情况
2. （二）人员及薪酬情况
3. （三）现金流量情况
4. （四）借款合同情况

本章回答经营趋势和资金压力。至少比较连续三年及最近一期；解释收入、毛利率、净利润、人工成本、经营现金流、借款余额和担保方式的变化。原因只采用材料能够支持的表述。

### 第三章：财务报表情况

固定顺序：

1. （一）合并资产负债表
2. （二）合并利润表
3. （三）合并现金流量表

优先使用审计报告或已明确合并口径的报表。检查资产总计与负债和所有者权益总计、现金净增加额与期初期末现金、利润表与现金流之间的重要勾稽关系。无法勾稽时标示差额，不得静默修改。

### 第四章：利润表明细情况

固定顺序：

1. （一）销售收入及毛利率情况
   - 1、分产品收入构成情况
   - 2、分产品毛利率构成情况
   - 3、产品收入变动及毛利率变动分析
   - 4、主要客户销售情况
2. （二）运营费用
3. （三）税务情况

客户表按材料允许的披露范围处理；源材料匿名时保持匿名。运营费用应突出异常变动和刚性支出。税务部分区分适用税率、优惠资格、申报缴纳和历史风险。

### 第五章：资产负债表明细情况

固定顺序：

1. （一）交易性金融资产
2. （二）应收账款
3. （三）预付账款
4. （四）存货
5. （五）固定资产
6. （六）合同负债
7. （七）应付账款

每项优先展示三年及最近一期数据、主要对象、账龄或结构，并说明余额变化、回收/周转、减值、权属或核算风险。没有数据时保留标题并写明材料缺口。

### 第六章：财务尽调发现的主要问题及风险揭示

问题数量和标题随项目变化。每项至少包括：

- 事实：主体、期间、金额、账户、交易和材料来源。
- 财务影响：对资产、负债、收入、成本、利润、现金流、税务或披露的影响；不能量化时说明原因。
- 应对：以“应对：”起首，给出可验证的整改动作和交易保护。

可按下列主题归并，避免把同一根因拆成大量碎片：

- 股权增资/转让税费与股份支付；
- 股东资金占用、关联交易与股权结构不确定性；
- 收入确认和证据链；
- 存货账实、成本结转、减值和盘点限制；
- 研发支出资本化/费用化；
- 职工薪酬、租赁、外币、政府补助等会计差错；
- 不相容岗位、研发、存货、运输和收入制度等内部控制缺陷。

## 二、筛选与措辞

- 报表概览不等于风险。趋势已在前五章充分说明且无交易处置价值时，不在第六章重复。
- 将三方报告的推测保留为待核事项，不使用“必然”“严重违法”等超过证据强度的措辞。
- 管理层口头解释标注为“据管理层说明”，并说明尚需何种凭证验证。
- 对重大账务调整给出方向，不在缺少完整底稿时擅自给出精确调整后净利润。
- 商业风险可在趋势分析中提示；只有直接影响估值、持续经营、现金流或交割安排时才进入第六章。

## 三、计算规则

- 毛利率 =（营业收入－营业成本）÷营业收入。
- 同比变动率 =（本期－上期）÷上期；上期为零时不计算百分比。
- 经营现金净额与净利润同时持续为负时，说明持续经营和融资依赖，但不得在无现金预算时断言资金耗尽时间。
- 所有重新计算值保留可复算底稿，并注明因四舍五入产生的尾差。
