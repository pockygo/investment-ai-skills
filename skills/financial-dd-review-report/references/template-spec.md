# 模板规格

## 模板证据

- 保留模板：`assets/review-report-template.docx`
- 来源样本：用户提供的“4-财务尽调审阅报告.docx”
- 来源 SHA-256：`2D0B4E9DB20915DA8E159B14BB7102F76018FF535716EA76F8A27B0E9115489D`
- 来源页数：31页；1个 A4 纵向节；21张表；1张图片。
- 页面尺寸：7560945 × 10693400 EMU（A4）。
- 页边距：上/下 914400 EMU，左/右 1144905 EMU；页眉距 540385 EMU，页脚距 705485 EMU。

## 视觉系统

- 封面左对齐、大留白：公司名22磅加粗，报告名18磅，报告月份14磅；底部居中页码。
- 正文宋体12磅、两端对齐、1.5倍行距、首行缩进24磅。
- 一级章节使用 `IPO Heading 2`：黑体14磅加粗。
- 二级章节使用 `IPO Heading 3`：黑体加粗。
- 三级章节使用 `IPO Heading 4`：加粗并带首行缩进。
- 普通说明可使用 `IPO Normal`；正文使用 `Normal`。
- 表格为黑色细边框、无彩色底纹，表头加粗居中，叙述列左对齐，数字列居中或右对齐；密集表格可使用9磅字号。
- 目录位于封面后，包含一级至三级标题并显示页码。

## 内容流

封面 → 目录 → 六个固定一级章节。前五章以表格和简短解释交替出现；第六章以连续问题段落为主，必要时插入量化测算表。

## 保真门槛

- 构建时必须先复制模板，不得覆盖模板。
- 保留模板的样式、页眉页脚、页码字段、主题、编号和表格外观。
- 可替换封面文字、目录、正文和表格；模板中的样例公司事实不得残留。
- Word/WPS 刷新目录后再渲染验收。
- 最终逐页检查：页码连续、表头重复、表格行不拆分、无裁切、无异常空白、无样例数据残留。
